Multigrid Inputs

incflo uses AMReX’s multigrid solver, MLMG, for the projections and for the implicit diffusion solves. The AMReX documentation on Linear Solvers describes the solver and its parameters (e.g. the available bottom solvers).

Projections

The MAC and nodal projections are done by AMReX-Hydro’s MacProjector and NodalProjector classes, which read their own options (verbosity, maximum number of iterations, bottom solver, …) with the prefix “mac_proj” or “nodal_proj”. These are documented in AMReX-Hydro’s documentation on projections inputs. The cell-centered projection (incflo.use_cc_proj = 1) is also done with the MacProjector, so it uses the “mac_proj” options.

In addition, incflo reads the following, which must be preceded by “mac_proj” or “nodal_proj”:
